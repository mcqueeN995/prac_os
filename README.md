## Практическая работа №1: `mycat` & `mygrep` & `myls` & `mychmod`

### `mycat`

Аналог утилиты `cat`. Выводит содержимое файлов в стандартный поток вывода.

#### Поддерживаемые флаги

| Флаг | Длинная форма           | Описание                                      |
|------|-------------------------|-----------------------------------------------|
| `-n` | `--number`              | Нумеровать все строки                         |
| `-b` | `--number-nonblank`     | Нумеровать только непустые строки             |
| `-E` | `--show-ends`           | Отображать `$` в конце каждой строки          |

> Флаг `-b` имеет приоритет над `-n` для пустых строк (соответствует поведению GNU `cat`).

#### Примеры использования

```bash
./my_cat/mycat file.txt
./my_cat/mycat -nE file.txt
./my_cat/mycat -bE file.txt
ls -l | ./my_cat/mycat -n
```

### `mygrep`

Аналог утилиты `grep`. Выполняет поиск подстроки (паттерна) в файлах или стандартном потоке ввода.

#### Примеры использования

```bash
./my_grep/mygrep pattern file.txt
./my_cat/mycat file.txt | ./my_grep/mygrep pattern
ls -l | ./my_grep/mygrep ".c"
```

### `myls`

#### Поддерживаемые флаги

Аналог утилиты `ls`. Выводит список файлов и директорий с детальной информацией.

| Флаг | Описание                                     |
|------|----------------------------------------------|
| `-a` | Показывать скрытые файлы (начинающиеся с `.`) |
| `-l` |Длинный формат вывода с метаданными           |

#### Примеры использования 
```bash
./myls
./myls -a
./myls -l
./myls -la
./myls -l -a ../..
./myls -l ../ -a
./myls .. -la
```

### mychmod
Аналог утилиты `chmod`. Изменяет права доступа к файлам и директориям.

#### Поддерживаемые режимы

##### Числовой режим:
 `766`, `0755`, `644` и тд.\
 Поддержка 3-х и 4-х значных режимов (включая специальные биты)

##### Символьный режим:
Категория: `u` (владелец), `g` (группа), `o` (остальные), `a` (все)\
Операции: `+` (добавить), `-` (убрать), `=` (установить точно)\
Права: `r` (чтение), `w` (запись), `x` (исполнение)\
Специальные права: `X` (условный x), `s` (setuid/setgid), `t` (sticky bit)\
Несколько операций через запятую: `u+r,g-w`

#### Примеры использования
```Bash
./mychmod +x file.txt
./mychmod u-r file.txt
./mychmod g+rw file.txt
./mychmod ug+rw file.txt
./mychmod uga+rwx file.txt
./mychmod 766 file.txt
./mychmod 755 file1.txt file2.txt
```
